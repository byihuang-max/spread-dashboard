# Smart Beta 定义

## 一句话

**Smart Beta = 一种不按市值加权、而是按某一条可量化规则选股/赋权的投资策略，长期存在系统性超额收益。**

---

## 四条硬标准

一个风格对照组要被称为 Smart Beta，必须同时满足：

| 标准 | 含义 | 反面例子 |
|------|------|---------|
| **① 可规则化** | 能用公开数据写出一条明确规则：选出谁、剔除谁、权重怎么定 | 靠 PM 经验判断龙头 → 不是 Smart Beta |
| **② 可投资** | 能做多高暴露组、做空低暴露组，形成多空组合 | 纯理论因子但无法交易 → 不是 Smart Beta |
| **③ 长期溢价** | 在足够长的时间窗口里，多空组合有正期望收益 | 今年涨明年跌、累计归零 → 不是 Smart Beta |
| **④ 有经济逻辑** | 溢价能解释为什么存在（风险补偿 / 行为偏差 / 制度约束），不是纯数据挖出来的 | 纯拟合、无法解释 → 是 overfitting，不是 Smart Beta |

---

## 与邻近概念的边界

```
市值加权指数      不是 Smart Beta
  ↓
Smart Beta      按规则选股/赋权，长期存在溢价
  ↓
因子投资         Smart Beta 的学术语言——把溢价拆成因子，多因子组合
  ↓
主动管理         主观判断，不是规则化
```

**Barra 因子 ≠ Smart Beta，但两者高度重叠：**

| 维度 | Barra 因子 | Smart Beta |
|------|-----------|------------|
| 目的 | 风险分解 | 收益获取 |
| 构建 | 统计回归 | 多头/空头分组 |
| 用法 | 跟踪误差归因 | 构建可投资组合 |
| 问的问题 | "我的风险从哪来？" | "我该买什么风格？" |

Barra 的 MOMENTUM 因子可以转化成"高动量减低动量"的 Smart Beta 策略。Barra 是原材料，Smart Beta 是成品。

---

## A股 Smart Beta 筛选漏斗

```
全市场可量化的信号                          ~200+
    ↓ 过滤: 可规则化 + 可投资
可构建多空组合的风格                        ~50
    ↓ 过滤: 长期溢价存在
历史上正期望收益                            ~20
    ↓ 过滤: 有经济逻辑可解释
真正的 Smart Beta                          ~14
    ↓ 按溢价强度 + PM 实战价值排序
优先落地                                   ~7
```

---

## 为什么 Smart Beta 对 FOF PM 重要

量化管理人的超额收益，拆开看三层：

```
超额收益 = 真 Alpha + Smart Beta 暴露 + 运气
```

PM 需要判断：
- 这个管理人的超额，多少来自真正的选股能力，多少来自恰好站在了某个 Smart Beta 的风口上？
- 如果某个 Smart Beta 正在持续溢价，是否应该主动配置暴露这个因子的基金？
- 如果某个 Smart Beta 已经极端拥挤，是否应该减配？

**风格轧差看板的角色：把 Smart Beta 的风向标可视化，让 PM 不做风格暴露的被动接受者，而是风格选择的主动决策者。**

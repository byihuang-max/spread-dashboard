# GAMT 看板日夜模式统一 CSS 变量架构（2026-05-31 定稿）

## 核心决策

从"两套 CSS 暴力覆盖"迁移到"一套 CSS 变量 + class 切换"。

## 旧架构（已废弃）

- 每个子页面硬编码白色样式
- 加载外部 `bloomberg-override.css`（50+ 行 `!important`）
- 页面内 `<style id="bb-override">` 再覆盖一层
- 切换时 reload iframe / 动态创建 link 标签
- 问题：跳变、闪白、结构不一致、维护地狱

## 新架构（当前标准）

### 原则
- **一套 HTML 结构**：白色和暗色共用，不存在"两个版本"
- **CSS 变量驱动**：`:root` 定义白色，`html.bb-dark` 定义暗色
- **0 reload**：切换 = add/remove `bb-dark` class + 0.35s transition
- **页面自包含**：不依赖外部 override 文件

### CSS 变量标准
```css
:root {
  --bg:#f5f6f8; --card-bg:#fff; --text:#2d3142; --text-sub:#8b92a5;
  --border:#e8eaef; --accent:#ff8c00; --grid-color:#f0f0f0;
  --note-bg:#f9fafb; --signal-bg:#f8f9fa;
  --tag-bg:rgba(0,0,0,0.05); --tag-text:#5a6070;
}
html.bb-dark {
  --bg:#0a0a0a; --card-bg:#0a0a0a; --text:#ccc; --text-sub:#888;
  --border:#2a2a2a; --accent:#ff8c00; --grid-color:#222;
  --note-bg:#111; --signal-bg:#0f0f0f;
  --tag-bg:rgba(255,255,255,0.06); --tag-text:#888;
}
```

### 组件风格
- 标题：左侧 3px 橙色竖线 + 橙色文字（无渐变/圆角背景）
- 卡片：无圆角、左侧橙色竖线、`var(--border)` 边框
- 字体：JetBrains Mono, SF Mono, monospace

### Chart.js 适配
- 注册全局 `themeGrid` plugin（afterLayout 钩子）
- 根据 `html.bb-dark` 动态设置 grid/tick 颜色
- 删掉所有 `grid:{color:"#f0f0f0"}` 硬编码

### ECharts 适配
- `window.bbEchartsColors()` helper 返回当前模式颜色
- 图表创建时调用 helper 获取 axis/legend 颜色

### Bootstrap 脚本（放 `</head>` 前）
1. themeGrid plugin 注册
2. 检测父页面模式 → 设置初始 class
3. 监听 postMessage `{type:"bb-theme", mode:"light"|"dark"}` → 切换 class + chart.update()

### Inline Style 覆盖（对付遗留硬编码）
对大量 inline style 的页面，用属性选择器：
```css
html.bb-dark [style*="background:#f8fafc"]{background:var(--sub-card-bg)!important}
html.bb-dark [style*="color:#374151"]{color:var(--text)!important}
```

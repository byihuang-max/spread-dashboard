## 需求背景

Roni 看到 VisionAlpha 的"全球经济事件日历"，要求在 GAMT 宏观层做一个类似模块。核心诉求：
- 本周 + 下周预告，全部北京时间
- 重要性信号灯（类似 VisionAlpha 的红黄绿）
- 国旗显示国家
- 每条事件列出股票/债券影响 + 逻辑
- 接入 update_all 自动更新

---

## 数据源选型

**Tushare `eco_cal` API**
- 优势：北京时间、含前值/预期/实际、免费、直连稳定
- 缺陷：**无重要性字段**，需要自己打标
- 覆盖：88条/两周（当前只到 T+2，滚动更新）
- 字段：`date, time, currency, country(category), event, value, pre_value, fore_value`

**iFind MCP**
- 有全球经济数据日历，但需要调研具体接口，时间成本高
- 暂不采用，优先用 Tushare 快速落地

---

## 核心设计决策

### 1. 重要性打标方案
因为 Tushare 不给重要性，自建 `event_library.json`（32条核心事件规则）：
- **关键词匹配**：`["议息", "利率决议", "FOMC"]` → 命中即采用该规则
- **重要性分级**：3=高(●●●) / 2=中(●●) / 1=低(●)
- **影响资产**：股票/债券 → 高/中/低
- **影响逻辑**：一句话解释为什么影响（如"央行利率决议直接影响无风险利率定价基准"）
- **未命中事件**：默认 ● 级 + "一般经济数据"

### 2. 时间窗口
- **本周一到下下周五**（T-7 ~ T+14，给足缓冲）
- Tushare 当前只给到 T+2，但每天 08:15/18:00 滚动更新会自动扩

### 3. 三段分桶
- **已公布**：有实际值 or 日期已过
- **本周**：今天到本周日
- **下周预告**：下周一到下周日

### 4. 核心事件卡片
- 只展示 **●●● 级 + 今日/本周**
- 顶部独立卡片，3-5 条，直接可读
- 符合 PM 实际用法：先看核心几个会动市场的事件，再翻详细表

### 5. 筛选功能
- **重要性**：●● 以上（默认）/ 仅 ●●● / 全部
- **国家**：全部 / 🇺🇸 美国 / 🇨🇳 中国 / 🇪🇺 欧元区 / 🇯🇵 日本 / 🇬🇧 英国

### 6. 国旗映射
25+ 货币全覆盖：
- USD🇺🇸 EUR🇪🇺 CNY🇨🇳 JPY🇯🇵 GBP🇬🇧 AUD🇦🇺 NZD🇳🇿 CAD🇨🇦 CHF🇨🇭 HKD🇭🇰
- KRW🇰🇷 INR🇮🇳 SGD🇸🇬 THB🇹🇭 IDR🇮🇩 BRL🇧🇷 ZAR🇿🇦 VND🇻🇳 MYR🇲🇾 等
- 未覆盖货币显示 🏳 白旗（影响观感，需补全）

## 前端设计

**Bloomberg 终端风格**
- 深色背景：`#0b0f14`（主背景）、`#111722`（卡片）

- 左侧红色竖线（`border-left: 3px solid #ef4444`）

**表格列**

## 核心代码片段

### event_library.json 规则示例
```json
{
  "keywords": ["议息", "利率决议", "基准利率", "FOMC"],
  "importance": 3,
  "equity": "高",
  "bond": "高",
  "logic": "央行利率决议直接影响无风险利率定价基准，加息利空风险资产、利好本币；降息反之。债市对利率变动最敏感，股市估值分母端受冲击。"
}
```

### 打标逻辑（calendar_calc.py）
```python
def match_event(event_name, rules):
    """按 keywords 命中返回规则；全不命中返回 None"""
    if not event_name:
        return None
    for rule in rules:
        for kw in rule['keywords']:
            if kw in event_name:
                return rule
    return None
```

### 前端展开逻辑（calendar.html）

body.querySelectorAll('tr.event-row').forEach(function(row){

    var idx = row.getAttribute('data-idx');
    var logic = body.querySelector('tr.logic-row[data-idx="' + idx + '"]');
    row.classList.toggle('open');
    logic.classList.toggle('open');
  });
});

## 教训与经验

1. **Tushare eco_cal 直连不用代理**
   - 开代理反而超时，关代理直连最稳

2. **事件库是开放的**
   - 遇到重要但未命中的事件可随时往 `event_library.json` 里加
   - 当前 32 条规则覆盖：央行议息/CPI/非农/GDP/PMI/ISM/零售销售/工业产出/社融/M1M2 等

3. **下周预告 0 条是数据源节奏限制**
   - Tushare 当前只给到 T+2，每天滚动更新会自动扩
   - 不是 bug，是数据源特性

4. **国旗映射要覆盖全**
   - 否则显示 🏳 白旗影响观感
   - 当前已覆盖 25+ 货币，基本够用

5. **Bloomberg 风格要统一**
   - 深色背景 + 几何符号 + monospace 字体
   - 不用装饰性 emoji，只用功能性状态图标（⚠️❗🔴🟢🟡🔵）

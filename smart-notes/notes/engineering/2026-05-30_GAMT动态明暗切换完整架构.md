# GAMT 看板动态明暗切换完整架构（2026-05-30 最终版）

> 标签: #Bloomberg主题 #CSS架构 #暗色模式 #iframe同步 #GAMT看板 #前端工程 #View-Transitions

## 文件职责

| 文件 | 职责 | 加载方式 |
|------|------|----------|
| bloomberg-shell.css | sidebar/header/Tab Bloomberg 风格 + :root 变量覆盖 | 静态 `<link>`，始终生效 |
| bloomberg-override.css | 全站暗色覆盖（内容区+框架全黑） | JS 动态创建，dark 时 enabled，light 时 disabled |
| 原始 `<style>` (index.html) | 基础布局+白色配色 | 内联，被 shell/override 的 !important 覆盖 |
| bloomberg-light.css | 已废弃，不再引用 | - |

## 页面加载流程

1. 浏览器解析 `<head>`
2. **静态 `<link href="bloomberg-shell.css">`** — 阻塞渲染，确保首帧就是 Bloomberg 风格（不闪蓝色）
3. **`<style>` 原始 CSS** — 定义默认变量、布局
4. **Bootstrap `<script>`（同步）**：
   - 读 localStorage("bbMode") → 决定 dark/light
   - `window.__bbMode = mode`
   - 动态创建 `<link id="bb-dark-css" href="bloomberg-override.css">`
   - light → `disabled=true`；dark → `disabled=false`
5. 渲染首帧（无闪烁）

## 主题切换流程（用户点击按钮）

```
bbToggleMode(event) → View Transitions API 圆形扩散动画
  ↓
applyMode(m):
  1. window.__bbMode = m
  2. localStorage.setItem("bbMode", m)
  3. bb-dark-css.disabled = (m==="light")
  4. body class: add/remove bb-light, bb-light-shell
  5. Chart.js defaults 更新 + update()
  6. postMessage 通知所有 iframe
```

### 圆形扩散动画（View Transitions API）
- 从按钮点击位置向外扩散 clip-path: circle()
- 500ms ease-out
- 不支持的浏览器 fallback 到直接切换
- CSS: `::view-transition-new(root){z-index:9999}` 禁用默认 crossfade

## iframe 子页面架构

### 首次加载（bootstrap）
```
读取 parent.__bbMode || parent.localStorage("bbMode")
  ↓
if(mode === "light"):
  → return（不加载暗色 CSS）
  → 页面用原始白色样式 + JetBrains Mono 字体
if(mode === "dark"):
  → document.documentElement.classList.add("bb-dark")
  → 激活内联 <style id="bb-override">
  → 创建 <link id="bb-override-link" href="bloomberg-override.css">
```

### 实时切换（message listener）
```
收到 postMessage {type:"bb-theme", mode:"dark"|"light"}
  ↓
1. add/remove "bb-dark" class → CSS 变量自动切换 → transition 动画
2. bb-override-link.disabled = (m==="light")
3. bb-override style media = "not all" | "all"
4. 【关键修复】切回 dark 时如果 bb-override-link 不存在则动态创建
5. Chart.js defaults 更新 + update()
```

### CSS 变量切换（子页面原始 CSS）
```css
:root { --bg:#f5f6f8; --card-bg:#fff; --text:#2d3142; --accent:#ff8c00; }
body { transition: background .35s ease, color .35s ease; }
html.bb-dark, html.bb-dark body { --bg:#0a0a0a; --card-bg:#0a0a0a; --text:#ccc; }
```

## 最终效果

- **暗色模式:** shell + override 同时生效 → 全站 Bloomberg 暗色终端风
- **亮色模式:** shell 生效 + override disabled → 框架暗色 + 内容区白色
- **切换动画:** 主框架圆形扩散(500ms) + 子页面 CSS 变量渐变(350ms)
- **字体统一:** 全站 JetBrains Mono，明暗切换不变

## 踩坑记录

1. **蓝色闪烁:** shell.css 必须静态 `<link>` 不能 JS 动态注入（FOUC）
2. **iframe 黑底:** JS 动态 inline style 无法被 CSS 覆盖，只能 reload 或用 CSS 变量
3. **切回暗色失败:** iframe 在 light 下首次加载时 bootstrap 跳过创建 link，切回 dark 时 listener 找不到 → 修复：listener 里动态创建
4. **rsync 权限:** 推文件后必须 chmod -R o+rX，否则 Nginx 403
5. **iframe reload 卡顿:** 改为 postMessage + class 切换，不再 reload

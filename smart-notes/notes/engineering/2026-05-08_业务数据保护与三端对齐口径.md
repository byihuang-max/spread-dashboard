# 业务数据保护与三端对齐口径

**日期**: 2026-05-08
**标签**: #数据保护 #三端对齐 #Git #生产环境 #事故复盘

---

## 摘要

代码三端 hash 对齐，业务数据以腾讯云为唯一真源不入 Git；须用 git rm --cached 真正移除 tracked 文件，避免 git reset --hard 覆盖线上数据。

## 正文

线上业务数据保护与三端对齐口径：代码看 Git commit，本地/Gitee/腾讯云三端 hash 一致；业务数据（团队基金池 fund_asset_pool.json、邮件订阅 email_subscribers.json、用户库 users.db*）以腾讯云生产环境为唯一真源，不进入 Git tracking，不做三端对齐。事故教训：rsync exclude 只能防同步覆盖，防不住 git reset --hard；必须 git rm --cached 真正移除 tracked 业务文件，并用 git ls-files 校验无输出。2026-05-08 已通过 commit 0c422cdc 移除 fund_asset_pool.json、email_subscribers.json、server/users.db-shm/wal，恢复 AWR20B 与黄晴梦邮箱。

# 源码打包前必须确认 admin 权限模块

## 规则

凡是涉及"打包源码给团队 / 回源给同事"的操作，**必须先询问 Roni 哪些模块属于 admin 权限、不应该包含在团队版本里**。不能自己判断直接打包。

## 触发关键字

- "回调给团队的源码包"
- "打包给XX"
- "源码发给他"
- "把代码给团队"
- "回源码"
- 任何涉及将现有模块代码交付给团队成员的场景

## 判断维度

| 类型 | 包含内容 | 示例 |
|------|----------|------|
| admin 权限（应剥离） | 产品池管理/审批/下架/API密钥写入/生命周期状态机 | pool_api.py、admin审批流程文档 |
| 团队权限（可保留） | 只读配置/数据拉取/渲染展示 | fetch_data.py、render_html.py、config.py（去密钥） |

## 背景

2026-05-10 团队基金优选模块打包时，首次打包包含了 pool_api.py（产品池增删改查审核）和生命周期管理函数。Roni 指出这些属于 admin 功能，不应给到团队成员。此后形成规则。

## 正文

## Git 仓库瘦身与三端同步的理解（2026-05-19）

### 核心概念

**三端同步（走 git）的内容：**
- .py 代码文件 ~20MB
- .html 前端页面 ~50MB
- 小 CSV/JSON（配置类）~80MB
- 图片/字体等 ~18MB
- 合计：168MB（2679 个文件）

**不走 git 的内容（各机器自己生成）：**
- 强势股涨停指数缓存 815MB
- 强势股行情缓存 270MB
- 红灯预警因子数据 59MB
- 期权情绪缓存 22MB
- 尽调库附件 151MB
- 合计：~1.3GB
- 每台机器自己跑 update_all.py 生成，互不干扰

### .git 是什么
- .git/ = 修订记录本，记录每次代码改动的历史
- git push 推的是这个记录本，远端收到后还原出完整代码
- 三端对齐 = 三台机器的代码内容一致

### 瘦身做了什么
- 删除 .git/ 里 financial_risk_factor.json 的 10 个旧版本快照（每个 60MB）
- 删除 venv/ 的历史记录
- 当前磁盘文件不受影响
- .git/ 从 ~1.4GB 降到 60MB

### 关键原则
- 大数据文件（每天更新的 CSV/JSON）不应进 git
- 已加 .gitignore 排除，以后不会再膨胀
- 缓存数据各机器独立维护，不依赖 git 同步

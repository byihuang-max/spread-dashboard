## 正文

# A股 Smart Beta 风格 Proxy Pattern：从风格语义到可计算对照组

## 核心问题
Smart Beta 风格系统不能只列风格名称，还必须为每个风格固定可计算 proxy：谁代表红利、谁代表成长、谁代表质量、空头/对照组是谁。否则后续风格轧差会口径混乱。

## 定义原则
每个风格固定五件事：风格名称 / 多头 proxy / 空头或对照 proxy / 分组规则 / PM解释口径。

## 三类 proxy pattern

### Pattern A：指数对照型
适合已有成熟指数的风格。优点是简单、稳定、可日更；缺点是成分和编制规则不完全透明。
- 红利：中证红利/申万红利/红利低波 vs 万得全A/中证全指/非红利组。含义：高股息现金流资产是否跑赢普通股票。
- 小盘：中证2000/国证2000 vs 沪深300/中证800。含义：小市值弹性是否跑赢大市值权重。
- 周期：有色、煤炭、钢铁、基础化工篮子 vs 食品饮料、医药、公用事业篮子。含义：经济弹性资产是否跑赢稳定现金流资产。

### Pattern B：个股分组型
适合没有好指数、但能用全市场数据稳定分组的风格，是最正统的 Smart Beta 口径。
- 低波：过去60/120日 realized vol 最低20%股票 vs 最高20%股票。含义：防御稳定资产是否跑赢高弹性彩票资产。
- 质量：ROE高、负债低、盈利稳定、现金流好的股票 vs ROE低、杠杆高、盈利波动、现金流差的股票。含义：好公司溢价是否有效。
- 动量：过去20/60日涨幅靠前且回撤不大的股票 vs 涨幅靠后或无趋势股票。含义：趋势延续是否有效。
- 反转：过去60/120/250日跌幅较大但无明显退市风险的股票 vs 同期涨幅较大的股票。含义：超跌修复是否压过强者恒强。

### Pattern C：语义篮子型
适合 PM 语言明确但单一指数不够干净的风格，需要构建篮子。
- 成长：创业板指/科创50/双创50/高研发高营收增速股票 vs 价值/红利/低估值篮子。含义：远期盈利想象力是否跑赢当期现金流。
- 价值：低PE、低PB、高FCF、高股息股票 vs 高PE、高PB、高成长预期股票。含义：便宜资产是否跑赢贵资产。
- 拥挤：低换手、低成交占比、低资金关注行业或股票 vs 高换手、高成交占比、高资金关注对象。含义：冷门资产是否开始反身性修复。

## 建议定稿口径
红利：中证红利/申万红利 → 对照全市场或非红利。
成长：双创50/创业板/科创50 + 高成长分组 → 对照价值。
价值：低PE/PB/高股息/现金流 → 对照成长。
低波：低历史波动股票组 → 对照高波。
小盘：中证2000 → 对照沪深300。
质量：高ROE低杠杆盈利稳定组 → 对照低质量组。
动量：近期赢家组 → 对照近期输家/静止组。
反转：中长期输家组 → 对照中长期赢家组。
拥挤：低拥挤行业/股票 → 对照高拥挤。
周期：周期行业篮子 → 对照防御行业篮子。
国企：央国企篮子 → 对照民企篮子。
北向：北向重仓组 → 对照轻仓组。

## 关键原则
风格 proxy 一旦定稿，后续看板和择时必须沿用同一口径。不要今天拿指数、明天拿行业、后天拿 Barra，避免风格净值不可解释。

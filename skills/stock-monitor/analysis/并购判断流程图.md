# 并购重组标的判断流程图

**适用场景：** 判断一只票是否值得纳入 B 类并购跟踪，以及如何分析其并购路径

---

## 第一步：触发条件判断（是否进入 B 类）

```
公告/新闻出现以下信号之一：
  │
  ├─ 停牌 + "筹划重大事项"
  ├─ 控股股东/实控人"拟转让股份"
  ├─ "重大资产重组"/"发行股份购买资产"
  ├─ 实控人变更预期（协议转让/表决权委托/一致行动解除）
  ├─ 借壳/反向收购信号（壳公司+新实控人）
  ├─ 产业基金设立（公司出资+外部 GP）
  │
  ▼
判断：是否有明确的"控制权/资产/股权"变动预期？
  │
  ├─ 是 → 纳入 B 类，启动深度跟踪
  └─ 否 → 保持 A 类常规监控
```

---

## 第二步：定性分类（什么类型的并购）

```
并购类型判断：
  │
  ├─ 类型 A：控制权转让（卖壳/卖股份）
  │   特征：实控人出让 → 新实控人入主
  │   核心问题：谁来买？买完做什么？
  │   案例：德昌股份
  │
  ├─ 类型 B：资产注入（买资产装进上市公司）
  │   特征：上市公司发行股份购买资产
  │   核心问题：注入什么？值多少钱？增厚多少利润？
  │   案例：ST赛为（预重整+装入存储/车规芯片）
  │
  ├─ 类型 C：借壳上市（壳+资产一起换）
  │   特征：壳公司原业务剥离 + 新资产注入 + 实控人变更
  │   核心问题：新资产质量？壳费多少？
  │
  ├─ 类型 D：产业整合（横向/纵向并购）
  │   特征：上市公司主动收购同行/上下游
  │   核心问题：协同效应？对价合理性？
  │
  └─ 类型 E：国资入主（地方政府/国资平台接盘）
      特征：民企实控人出让 → 国资平台接盘
      核心问题：国资的产业逻辑？后续注入预期？
      案例：德昌股份（路径 A）
```

## 第三步：信息采集（API → Kimi → Claude）

```
Step 0: API 硬事实（0 成本）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Tushare:
    ● 股东名单 + 持股比例 + 质押情况
    ● 减持记录
    ● 注册地/办公地
    ● 财务数据（营收/利润/PE/PB）
    ● 近期公告日期
  iFinD:
    ● 公告标题+片段
    ● 舆情标题+片段

  输出 → 提取关键词集合：
    人名 / 地名 / 机构名 / 事件关键词 / 行业

Step 1: Kimi 第一层 — 事实补充（4-5 次搜索）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  必搜维度：
    1. 实控人/股东背景（家族关系、其他资产、历史）
    2. 事件时间线（停牌/复牌/公告序列）
    3. 公司基本面（主营/竞争力/行业地位）
    4. 注册地 + 产业基金/国资/地方政府  ← 不可遗漏
    5. 治理结构/管理层变动

Step 2: Kimi 第二层 — 买方/标的推断（3-4 次搜索）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  根据类型不同，搜索方向不同：

  控制权转让（类型 A/E）：
    ● 潜在买方 + 市场猜测
    ● 注册地国资平台 + 产业基金历史投资
    ● 同行业近期控制权转让案例

  资产注入（类型 B/C）：
    ● 新实控人旗下其他资产
    ● 承诺注入的标的公司基本面
    ● 同行业可比交易估值

  产业整合（类型 D）：
    ● 上市公司公开表态的并购方向
    ● 行业内可收购标的（融资阶段/规模/注册地）
    ● 产业基金已投项目

Step 3: Kimi 第三层 — 线索验证（1-3 次搜索）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ● 具体基金名/买方名 + 公司名 → 验证关系
  ● 具体标的公司 + 融资/股权 → 验证可行性
  ● 纳税地一致性验证

  原则：搜到具体名字+金额+时间才写进底稿

Step 4: Claude 结构化输出（1-2 次）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  汇总 Step 0-3 → 生成底稿 markdown
```

## 第四步：核心判断框架

```
对每只 B 类票，必须回答 5 个核心问题：

┌─────────────────────────────────────────────────────────────┐
│ Q1: 谁在卖？为什么卖？                                       │
│     ● 主动 vs 被动（质押爆仓/债务/主动战略选择）             │
│     ● 卖方的议价能力（有没有时间压力）                       │
├─────────────────────────────────────────────────────────────┤
│ Q2: 谁可能买？买方的逻辑是什么？                             │
│     ● 产业逻辑（垂直整合/横向扩张/技术互补）                 │
│     ● 财务逻辑（低估值套利/壳价值）                          │
│     ● 政策逻辑（地方政府招商/国资布局）                      │
│     ● 纳税地优先考量（地方基金出资方的核心诉求）             │
├─────────────────────────────────────────────────────────────┤
│ Q3: 交易完成后，公司会变成什么？                             │
│     ● 注入什么资产？（具体标的/方向）                        │
│     ● 利润增厚多少？（量化）                                │
│     ● 估值体系是否切换？（从 A 行业 PE 切到 B 行业 PE）     │
├─────────────────────────────────────────────────────────────┤
│ Q4: 当前处于什么阶段？下一个节点是什么？                     │
│     ● 筹划期 / 停牌期 / 方案公布 / 股东大会 / 证监会审批    │
│     ● 终止后是否有重启可能（终止原因分析）                   │
│     ● 时间窗口判断（多久内没动静就降级）                     │
├─────────────────────────────────────────────────────────────┤
│ Q5: 估值怎么看？                                            │
│     ● 情形 A：仅控制权转让（控制权溢价 30-80%）             │
│     ● 情形 B：转让 + 资源导入（利润增厚 → PE 重估）        │
│     ● 情形 C：平台化重估（估值体系切换）                    │
│     ● 每个情形给具体价格区间                                │
└─────────────────────────────────────────────────────────────┘
```

## 第五步：确定性分层标注

```
所有信息必须标注确定性等级：

■ 确定（公告/工商/财报）
  → 直接引用，标注来源
  → 例：持股比例、注册地、产业基金规模

■ 高概率推断（多维度交叉验证）
  → 标注推断逻辑 + 支撑维度数量
  → 例：盐城国资接盘（已有产业基金合作+注册地一致+基金体系800亿）

■ 中概率推断（单一维度 + 行业惯例）
  → 标注为"推测"，列出假设条件
  → 例：可能收购线控底盘公司（基于德昌在研方向推断）

■ 低概率/行业参考（无直接数据支撑）
  → 明确标注"行业参考，非确定性推断"
  → 例：5家线控底盘融资公司列表
```

## 第六步：信号监控 + 升降级

```
B 类票的生命周期管理：

纳入 B 类
  │
  ├─ 每日监控（stock_monitor.py 自动）
  │   ● 公告/舆情命中资本运作关键词 → 飞书卡片标红
  │   ● 减持/质押变动 → 信号
  │
  ├─ 定期复查（每周/两周，人工触发）
  │   ● Kimi 补搜最新进展
  │   ● 更新底稿
  │
  ├─ 重大事件触发（即时）
  │   ● 复牌/新公告/方案公布 → 全量更新底稿
  │
  ├─ 升级条件
  │   ● 方案公布 → 加入"交易结构分析+对价合理性判断"
  │   ● 过会/获批 → 加入"实施时间表+套利空间计算"
  │
  └─ 降级条件
      ● 终止后 6 个月无新动向 → 降为 A 类
      ● 实控人明确表态不再推进 → 降为 A 类
      ● 公司基本面恶化（ST/退市风险）→ 移出 watchlist
```

## 附：判断清单（每只 B 类票必填）

| 维度 | 问题 | 答案 |
|------|------|------|
| 卖方动机 | 主动/被动？有无时间压力？ | |
| 买方画像 | 最可能的买方类型？概率排序？ | |
| 纳税地 | 注册地在哪？当地有无产业基金？ | |
| 产业基金 | 有无已设立的产业基金？GP 是谁？历史投资？ | |
| 交易类型 | A/B/C/D/E 哪种？ | |
| 当前阶段 | 筹划/停牌/公布/审批/终止？ | |
| 下一节点 | 什么时候有新信息？观察窗口多长？ | |
| 估值区间 | 三种情形各多少？ | |
| 降级条件 | 什么情况下降为 A 类？ | |
| 确定性 | 哪些是确定的？哪些是推测？ | |

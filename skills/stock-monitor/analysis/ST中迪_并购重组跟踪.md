## 8. 收购路径推演

### 最可能路径：地方国资主导的资产注入/战略重组

```
达州国资委主导 → 筛选本地优质资产（如能源、基建、文旅等）
→ 资产评估及方案设计 → 国资委审批 → 董事会/股东大会审议
→ 交易所审核 → 证监会注册（如涉及发行股份）→ 完成过户
```

**时间预估：** 9-15个月
**核心逻辑：** 地方政府保壳意愿强，达州国资体系内可能有可注入资产

### 备选路径一：引入外部战略投资者（协议转让控股权）

```
国资委挂牌转让控股权 → 产权交易所公开征集受让方
→ 新实控人入主 → 注入新资产/变更主业 → 完成重组
```

**时间预估：** 12-18个月
**核心逻辑：** 若本地无合适资产，可能引入外部产业资本借壳

### 备选路径二：破产重整

```
债权人/公司申请破产重整 → 法院受理 → 引入重整投资人
→ 债务清偿方案 → 资产注入 → 恢复上市
```

**时间预估：** 18-24个月
**核心逻辑：** 若债务问题严重且常规重组无法推进，可能走司法重整路径

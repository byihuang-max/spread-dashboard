## 八、结构规律总结（并购池选票参照）

| 维度 | 规律 |
|------|------|
| **支付方式** | 发行股份为绝对主流（>90%），现金占比通常 <30%；可转债是新趋势 |
| **收购比例** | 100% 全资收购最多；少数股权（已控股→全资）审核最快 |
| **配套募集** | 约 60% 案例有配募，金额通常为交易对价的 20-50% |
| **业绩承诺** | 产业并购几乎都有（3年期）；同控注入可不设 |
| **审核周期** | 简易审核 13-50 天；普通 75-141 天；复杂 200+ 天 |
| **成功行业** | 半导体 > 新能源 > 汽车零部件 > 能源/电力 > 新材料 |
| **失败高发** | 跨界+对价谈不拢+标的未盈利+交易对方多（>20人） |
| **政策偏好** | 新质生产力（六成标的）、产业整合（五成）、大股东注资（两成） |

### 选票启示

**高成功概率特征（并购池优先纳入）：**
1. 产业链上下游整合（非跨界）
2. 标的已盈利且增速明确
3. 交易对方 ≤5 人
4. 控股股东/实控人有明确推动意愿
5. 行业属于新质生产力（半导体/新能源/高端制造）
6. 已有产业基金/国资合作基础

**高风险特征（谨慎纳入或观察）：**
1. 跨界并购（尤其传统→科技）
2. 交易对方 >10 人
3. 标的未盈利
4. 筹划超过 6 个月未出方案
5. 估值争议大（增值率 >300%）

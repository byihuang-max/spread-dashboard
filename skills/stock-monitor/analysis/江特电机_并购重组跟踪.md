## 8. 收购路径推演

### 最可能路径（主路径）

```
实控人变更完成 → 发布并购重组预案 → 深交所审核通过 → 证监会审核（当前）
→ 证监会核准 → 发行股份+支付现金完成交割 → 标的并表 → 锂资源业务整合
```

**核心逻辑**：新实控人入主后推动公司向新能源上游（锂资源）延伸，通过收购宜春银锂新能源实现"电机+锂资源"双主业布局，契合宜春市锂电产业集群战略。

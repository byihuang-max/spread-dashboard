# GAMT 权限管理说明

## 权限层级

| 层级 | tier 值 | 说明 |
|------|---------|------|
| 管理员 | is_admin=1 | 全部可见，可管理用户和权限 |
| 团队 | tier=2 | 内部团队成员 |
| 重要客户 | tier=1 | 付费/核心客户 |
| 普通用户 | tier=0 | 免费/试用用户 |

母子嵌套关系：管理员 > 团队 > 重要客户 > 普通用户

模块设 min_tier=1（重要客户+），则团队和管理员也能看到。

## 权限存储

- 数据库：`server/users.db` → `module_permissions` 表
- 每个模块一行：module_key + min_tier
- 未配置的模块默认 min_tier=0（所有人可见）

## 设置权限的方式

### 方式一：管理后台（日常推荐）

1. 打开管理后台 `admin.html`
2. 切到"模块权限"Tab
3. 下拉选择每个模块的最低权限等级
4. 改完即时生效，不需要重启

### 方式二：配置页面（批量设置）

1. 打开 `module_permissions_config.html`
2. 填完所有模块的权限
3. 点"保存配置"生成结果
4. 把结果发给 AI 助手写入数据库

## 新增模块时的流程

1. 写好模块代码
2. 在 `server/module_registry.py` 注册模块（name、scripts、aliases 等）
3. 在 `index.html` 侧边栏加入导航项，带 `data-module="模块key"` 属性
4. 去管理后台 → 模块权限 Tab → 给新模块设权限
5. 如果模块还没做完，在侧边栏导航项里加"待完善"标签：
   ```html
   <span style="font-size:10px;background:#ff9800;color:#fff;padding:1px 5px;border-radius:3px;margin-left:4px;vertical-align:middle">待完善</span>
   ```

## 刷新机制

- 权限改动实时生效（改数据库后下次请求即生效）
- 只有改了 Python 代码才需要重启服务
- 重启命令：
  - 本地：`pkill -f refresh_server.py && cd server && python3 refresh_server.py &`
  - 腾讯云：`sudo systemctl restart gamt`
